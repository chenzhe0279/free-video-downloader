## 1. 结论

在**不改动下载 / 在线预览 / 去水印 / AI 问答核心链路**的前提下，为「AI 视频总结」补齐三块内容消费能力：

1. **Markdown 笔记阅读视图**：总结页默认渲染排版精美的笔记（标题层级、目录、引用、列表、表格、代码块、可点击时间戳），同时保留原有结构化卡片视图切换；
2. **思维导图全屏 + 高清导出**：内联区域加高，支持页面内全屏，支持导出 2x/3x PNG 与 SVG；
3. **字幕文件下载**：AI 总结完成后，在「文稿」页下载 SRT / VTT / TXT / MD，平台字幕与 ASR 逐字稿都支持。

技术选型：`markdown-it@15` + `dompurify@3`；思维导图基于现有 `markmap-view@0.18.13` 手写 SVG → Canvas 导出；全屏采用 `Teleport` + fixed 弹层；字幕文件由后端新模块生成，零额外成本。

图例：✅ 官方明确支持；⚠️ 部分支持/形式受限；❌ 明确不支持；❓ 未找到公开证据；— 不适用。

**关键结论：**

1. **Markdown 精排版是明确空档**：五家没有一家官方宣称把总结渲染成带目录、锚点、时间戳 chip 的 Markdown 文档流；本项目做 GFM 渲染 + 目录 + 可点击时间戳，是低成本、高感知的差异化。
2. **“导图全屏 + 2x/3x PNG + SVG、无水印”没有竞品公开承诺**：这是需求 2 的机会点，验收标准应包含“图完整、可印刷、矢量备份”。
3. **字幕下载要做格式矩阵**：竞品普遍支持 SRT/TXT，BibiGPT 多做 MD/VTT/双语；只给 SRT 不够，至少 SRT/VTT/TXT/MD 四选一。
4. **导出不要锁付费墙**：竞品普遍在时长/次数/模型上收费，导出基本不锁；本期所有导出免费、无水印。
5. **时间戳要成为全链路可点击单元**：章节、要点、字幕行共用同一套 seek 机制，阅读视图里的时间戳也应可跳转。

## 3. 现有项目核对

### 3.1 架构事实

- 前端：Vue 3.5 + Vite 6 + Tailwind 3，无路由；`Home.vue` 持有解析/预览/下载状态，`AiSummaryPanel.vue` 自包含总结/章节/文稿/导图/问答五个标签。
- 后端：FastAPI + yt-dlp + httpx + Pydantic + imageio-ffmpeg；任务、总结缓存、额度全部在内存。
- 现有总结链路：`POST /api/summary` → `summary_manager` → 平台字幕或 ASR → `deepseek-flash` JSON → `build_markdown()` → 前端轮询。
- 文稿：`GET /api/summary/{task_id}/transcript` 返回 `segments`，前端只做在线分页展示与复制。
- 思维导图：`markmap-view@0.18.13`，`MindmapTree.vue` 固定 540px 高，仅支持缩放/拖拽/折叠。
- Markdown：`SummaryPayload.markdown` 已生成，但前端只用于复制/下载 `.md`，页面从未渲染；时间戳是纯文本。

### 3.2 现有行为限制

| 项 | 现状 |
|---|---|
| Markdown | 页面无渲染；AI 文本未转义，特殊字符会破坏结构；时间戳不可点击 |
| 思维导图 | 540px 高、无全屏、无导出；未安装任何导出依赖 |
| 字幕 | 只能在线阅读/复制文本，没有文件下载；ASR 时间戳约 1 分钟粒度 |
| 任务 TTL | 总结结果默认保留 30 分钟；过期后文稿/字幕都返回 404 |
| 测试基线 | 后端 62 个 unittest 全部通过；前端无测试框架，以 `npm run build` + 无头 Chrome 验收 |

### 3.3 本机环境结论

- Node v24 / npm 11，registry 已配置 npmmirror；**全局 npm cache 目录被沙箱拒绝**，需用 `--cache runtime/npm-cache`。
- Chrome 可用；`backend/tests/browser_e2e.py` 与 `qa_browser_e2e.py` 已有 CDP 验收脚本可复用。
- markmap 0.18.13 **没有导出 API**，节点文字使用 `<foreignObject>`；1.x 虽有内置 `toPNG`，但节点结构重写、刚发布，本期不升级。
- `backend/.env` 已配置真实 DeepSeek Key（不读取、不落盘），可做一次真实链路验收。

## 4. 目标与验收标准

### 4.1 用户故事

1. 我生成总结后，默认看到一篇排版精美的笔记：标题、目录、引用、列表，时间戳可以点回视频；
2. 我想快速看结构时切到「卡片」视图，TL;DR、要点、概念卡片仍在；
3. 我看思维导图时嫌区域小，点全屏铺满屏幕看分支，并下载一张高清 PNG 发给同学；
4. 我想自己拿字幕去做总结，在文稿页下载 SRT / TXT / Markdown。

### 4.2 成功标准

| 需求 | 成功标准 |
|---|---|
| R1 Markdown | 真实视频总结完成后，笔记视图 h1–h3、目录、引用、列表、表格样式正确；时间戳可 seek；可切卡片视图且刷新后记住偏好；复制/下载 .md 可用；恶意 HTML/链接被消毒 |
| R2 思维导图 | 内联高度 ≥600px；全屏覆盖视口、ESC 关闭、滚动锁定恢复；PNG 2x/3x 完整无裁剪、非空白；SVG 可独立打开；375px 宽度可用 |
| R3 字幕 | 文稿页可选 SRT/VTT/TXT/MD 下载；SRT/VTT 时间轴合法、UTF-8 中文正常；TXT 纯文本；MD 含元信息；平台字幕与 ASR 都支持 |
| 回归 | 现有 62 后端测试全过；`npm run build` 通过；下载/预览/去水印/总结/问答不受影响 |

### 4.3 本期明确不做

- PDF 导出、字幕翻译/双语字幕、说话人分离；
- 解析后未生成总结即可下载平台字幕的独立 API（本期只覆盖总结任务内的字幕）；
- markmap 1.x 升级、`html-to-image` / `dom-to-image` / Playwright 依赖；
- 原生 Fullscreen API（改用页面内弹层，避免 iOS 兼容问题）；
- 问答回答的 Markdown 渲染（保持现状，后续可复用同一组件）。

## 5. 技术选型与决策记录

### 5.1 Markdown 渲染：markdown-it + DOMPurify

| 方案 | 版本 | 体积（gzip） | 只读适配 | XSS | 维护 |
|---|---|---|---|---|---|
| `markdown-it` + `dompurify` | 15.0.3 / 3.4.17 | 约 52KB | 完全自控，输出 HTML 交给 Tailwind 样式 | 显式 DOMPurify | 活跃 |
| `bytemd` + `@bytemd/vue-next`（ByteMD） | 1.22.0 | 约 132KB（+parse5 179KB） | Viewer 无内置样式，需自带主题；GFM/高亮各加插件 | 内置 rehype-sanitize | **v1 已冻结（2025-02 后无提交）** |
| `md-editor-v3` 的 `MdPreview` | 7.1.0 | 约 317KB | 自带主题，适合预览+编辑 | 内置 xss | 活跃 |

**决策：markdown-it + DOMPurify。** 理由：只读场景不需要编辑器 runtime；体积约为 ByteMD 的 40%、MdPreview 的 16%；输出结构简单，Tailwind 可精确控制排版；XSS 边界清晰、便于写测试。用户原始建议的 ByteMD 因维护冻结且 Viewer 不含样式，不作为首选。

配置：`html: false`（原始 HTML 转义）、`linkify: true`、GFM 表格/删除线默认开启；DOMPurify 使用 `USE_PROFILES: { html: true }`，允许 `target/rel` 供外链使用。

### 5.2 导图导出：markmap 0.18 手写 SVG → Canvas

- 已装 `markmap-view@0.18.13` **没有导出 API**，节点用 `<foreignObject>` 渲染；
- Chrome/Edge 下把 SVG 序列化为 **data URL**（不能用 blob URL，旧版 Chrome 会污染 canvas）后绘制到 Canvas 可行；
- Safari 对 `foreignObject` 的安全模型更严格，可能失败 → PNG 失败时降级导出 SVG；
- 不升级 1.x：其节点内容结构从 HTML 字符串改为结构化内容，现有 `toPureNode` 需重写，刚发布不适合生产；
- 不引入 html-to-image/dom-to-image：它们同样依赖 foreignObject，Safari 问题叠加，且本需求只需纯文字导图。

实现要点：取 `getBBox()`、加 32px padding、克隆 SVG、移除 d3 zoom transform、按倍率设置 width/height、给 foreignObject 子元素补 XHTML 命名空间、注入胶囊 CSS、等待字体、Canvas 白底、`toBlob('image/png')`、单边上限 16384。

### 5.3 全屏：Teleport + fixed 弹层

- iPhone 不支持任意元素 Fullscreen API，Safari 全屏下 ESC 事件也不可控；
- 弹层用 `Teleport to body`，避免祖先 `transform/filter/backdrop-filter` 影响 fixed 定位；
- 自己处理 ESC、遮罩关闭、body 滚动锁定；桌面/移动端行为一致。

### 5.4 字幕导出：后端纯 Python

- 数据已在 `task.segments`，无需调用 AI、无需落盘；
- 后端统一生成 SRT/VTT/TXT/MD，保证格式与编码正确；
- 新增 `Content-Disposition` 附件响应；不修改现有 `transcript` JSON 接口。

## 7. 需求 1：Markdown 笔记阅读视图

### 7.1 后端 Markdown 输出增强

文件：`backend/app/services/summary/markdown.py`

1. **文本转义**：所有来自 AI 的标题、要点、概述、章节标题、概念、关键词先折叠换行为空格，再转义 Markdown 特殊字符：`\`、`` ` ``、`*`、`_`、`[`、`]`、`<`、`>`、`|`。防止 AI 输出中的 `[点击](javascript:...)`、`*`、HTML 标签破坏结构或注入。
2. **时间戳链接**：
   - 章节：`### [00:00](#t=0) 章节标题`
   - 要点：`1. **要点标题** [00:00](#t=0)`
   - 概念：`- **术语**：解释`
   - 秒数取整；`timestamp_seconds` 为 `None` 时不输出链接。
3. 保留现有结构（标题、平台/作者/时长、原视频、一句话总结、内容概述、关键词、章节大纲、核心要点、关键概念、思维导图、AI 声明）。
4. 关键词使用行内代码包裹（先清洗反引号），保持可读。
5. 不改 `SummaryPayload`/任务/缓存结构。

### 7.2 前端渲染

新增文件：

- `frontend/src/utils/markdown.ts`：markdown-it 单例、`renderMarkdown()`、`extractHeadings()`；
- `frontend/src/components/MarkdownNote.vue`：目录 + 文章容器 + 时间戳/外链行为。

`MarkdownNote` 行为：

| 能力 | 实现 |
|---|---|
| 渲染 | `markdown-it` 渲染 → DOMPurify 消毒 → `v-html` |
| 标题锚点 | 遍历 token 给 `heading_open` 注入 `id="md-h-{n}"`，同时返回目录数组 |

## 8. 需求 2：思维导图全屏与高清导出

### 8.1 `MindmapTree.vue` 改造

- 新增 `height` prop（默认 `600px`），容器使用内联 style 高度；
- 将根节点胶囊样式迁移到 markmap `OPTIONS.style`（会被写入 SVG `<style>`，页面与导出同时生效），移除对 Vue scoped 样式的依赖；
- 暴露：
  - `fit(): Promise<void>`
  - `expandAll(): Promise<void>`：把全部节点 `fold=0` 后重绘并 fit
  - `exportSvgString(): Promise<{ content: string; width: number; height: number }>`
  - `exportPng(scale: 2 | 3): Promise<Blob>`

### 8.2 导出算法

1. `await document.fonts.ready`；
2. `markmap.g.node().getBBox()` 取内容边界，padding 32px；
3. 克隆 SVG：补 `xmlns`/`xmlns:xlink`，移除 d3 zoom 的 transform，给 foreignObject 子元素补 `xmlns="http://www.w3.org/1999/xhtml"`，隐藏折叠圆点与高亮层；
4. 设置 `viewBox` 与目标像素 `width/height`（逻辑尺寸 × scale）；
5. `XMLSerializer` → `data:image/svg+xml;charset=utf-8,...` → `Image.decode()`；
6. Canvas 白底 + `drawImage`；单边 > 16384 时自动降低倍率并提示；
7. `canvas.toBlob('image/png')`；失败抛可读错误，由外壳提示并提供 SVG 下载；
8. SVG 下载直接序列化字符串为 `image/svg+xml` Blob。

### 8.3 `MindmapViewer.vue` 外壳

- 顶部工具条：标题、适应屏幕、展开全部、导出（PNG 2x / PNG 3x / SVG）、全屏；
- 内联 `<MindmapTree :height="'600px'">`；
- 全屏：`Teleport to="body"` + `fixed inset-0 z-[100]`，弹层内工具栏 + 图（`calc(100dvh - 56px)`）；
- 打开全屏：锁 `body` 滚动；ESC/遮罩/关闭按钮退出；关闭后恢复滚动并 `fit()`；
- 移动端：工具栏横向滚动、按钮紧凑；
- 导出状态：loading 禁用、成功“已开始下载”、失败显示原因；
- 导出不改变当前视图缩放；默认 `initialExpandLevel: -1` 全展开，用户折叠后导出当前展开内容，工具条提供“展开全部”。

### 8.4 文件名与下载

## 9. 需求 3：字幕文件下载

### 9.1 后端导出模块

新增 `backend/app/services/summary/exporters.py`：

```python
def to_srt(segments: list[TranscriptSegment], duration: float | None) -> str
def to_vtt(segments: list[TranscriptSegment], duration: float | None) -> str
def to_txt(segments: list[TranscriptSegment]) -> str
def to_markdown(segments, *, title, source, language, duration) -> str
def subtitle_filename(task, ext: str) -> str
```

时间规则：

- SRT：`HH:MM:SS,mmm --> HH:MM:SS,mmm`；VTT：`HH:MM:SS.mmm --> HH:MM:SS.mmm`；
- `end_seconds` 有效（> start）时优先使用；
- 缺失时取下一段起点；最后一段取 `start + 3s`；
- 不超过视频时长；保证 `end > start`；过滤空文本；
- ASR 段落可能跨 60 秒，保持原分片时间，不伪造更细粒度。

格式内容：

| 格式 | 内容 |
|---|---|
| SRT | 标准字幕序号 + 时间轴 + 文本 |
| VTT | `WEBVTT` 头 + 标准时间轴 + 文本 |
| TXT | 纯文本按段换行，无时间戳，方便直接喂给其他 AI |
| MD | 标题、来源/语言/段数、时间戳列表（`- [00:00] text`）、免责声明 |

### 9.2 API

`GET /api/summary/{task_id}/subtitles?format=srt|vtt|txt|md`

| 场景 | 响应 |
|---|---|
| 正常 | 200，对应 MIME + `Content-Disposition: attachment`（RFC 5987 中文文件名）+ `Cache-Control: no-store` |
| 任务不存在/过期 | 404“总结任务不存在或已过期” |
| 字幕尚未生成 | 409“字幕尚未生成，请等待总结完成” |
| 非法 format | 422（FastAPI 枚举校验） |
| 生成异常 | 500“字幕生成失败” |

- 不扣 AI 额度、不延长 TTL、不新增配置；
- 文件名：`{标题}-字幕-{平台字幕|AI语音识别}.{ext}`，使用 `safe_filename` 截断；
- 路由放在 `/{task_id}/transcript` 之后，避免吞路径。

### 9.3 前端

- `client.ts`：`SubtitleFormat = 'srt' | 'vtt' | 'txt' | 'md'`；`summarySubtitle(taskId, format)` 返回 `{ blob, filename }`，解析 `Content-Disposition` 的 `filename*`；
- `AiSummaryPanel.vue` 文稿页工具栏：格式 `<select>` + “下载字幕”按钮，默认 SRT；下载中禁用；失败显示中文错误；ASR 来源提示“时间戳约 1 分钟粒度”；
- 下载文件名优先使用响应头，失败时回退 `safeFilename(title)` + 后缀。

## 11. 失败模式与处理

| 场景 | 行为 |
|---|---|
| Markdown 为空/旧任务无 `#t=` 链接 | 面板回退卡片视图；时间戳按普通文本展示，不报错 |

| 全屏打开后切换标签/页面 | 组件卸载时恢复 body 滚动与 keydown 监听 |
| 任务过期/字幕未生成/格式非法 | 404/409/422，前端中文提示 |
| ASR 时间粒度粗 | UI 与文档明确约 1 分钟；SRT/VTT 时间轴按分片补齐，不伪造 |
| 新增依赖安装失败 | 使用 `--cache runtime/npm-cache` 重试；仍失败则记录原因并用临时缓存目录 |
| 真实 AI 网络/额度异常 | E2E 回退离线 fixture + mock DeepSeek，文档记录实际验证范围 |

### 14.4 实施中发现并修复的问题

1. **根节点胶囊遮挡分支**：迁移到 markmap `OPTIONS.style` 后，根节点内层 `div` 继承 `width: var(--markmap-max-width)`（250px），胶囊背景比文字宽很多，遮住二级分支。修复为 `width: max-content; max-width: var(--markmap-max-width)`，页面与导出同时生效。

3. **同名下载被无头 Chrome 拒绝**：重复运行验收时 Chrome 对同名文件不再下载；E2E 改为每次使用 `runtime/proof/v06-downloads-<时间>` 独立下载目录，并把最终产物复制为稳定文件名。
4. **移动端全屏工具栏标题被挤扁**：375px 下按钮占满宽度，标题只剩半个字符；改为移动端隐藏标题区、按钮靠右横向滚动。
5. **导出菜单被工具栏 overflow 裁切**：内联工具栏原先使用 `overflow-x-auto`，绝对定位的下拉菜单被父级裁切，只露出 `PNG 2x` 并出现滚动条；改为把菜单 `Teleport to body` 并用 fixed 定位（根据按钮 `getBoundingClientRect()` 计算上下/右对齐），同时内联工具栏取消横向滚动、桌面一行、窄屏自然换行，菜单增加“分享/文档、打印级、矢量备份”说明。
6. **Windows 文件占用**：旧导出图被系统 ACL 锁定，无法删除；改用独立下载目录规避，不影响产品代码。

### 14.5 导出菜单二次验收（2026-11-14）

## 15. 假设与已知限制

### 假设

- 字幕文件由服务端从统一 `segments` 生成，不保留平台原始字幕二进制；
- 导图全屏为页面内弹层，不调用原生 Fullscreen API；
- 字幕下载只覆盖已生成的总结任务，不新增“解析后直接下载平台字幕”的入口；
- 新增前端依赖通过 npmmirror 安装，使用 `runtime/npm-cache` 绕过沙箱缓存限制。

### 已知限制

- Safari/iOS 对 `foreignObject` → Canvas 支持不稳定，PNG 可能失败，需使用 SVG 降级；
- ASR 字幕时间戳约 1 分钟粒度，不如平台字幕精确；
- 任务 30 分钟后过期，字幕/文稿随之失效；
- 导图节点被折叠时导出仅包含当前展开内容；
- 单边超过 16384px 的导图会自动降低导出倍率；
- Markdown 笔记视图依赖服务端生成的新格式；无 `#t=` 链接的旧内容按纯文本展示；
- 问答回答仍未渲染 Markdown，不在本期范围。
