# 万能视频下载站 · 需求分析文档

> 版本：v0.1（MVP 阶段）
> 更新日期：2026-11-12
> 关联文档：[方案设计文档](./design.md)

---

## 1. 背景与问题

用户有把网络视频保存到本地的强烈需求，但现状存在三类摩擦：

1. **平台不提供下载能力** —— 部分站点完全没有导出入口。
2. **下载体验差** —— 清晰度被限制、需要安装插件/客户端、不支持批量。
3. **跨端不一致** —— 手机上尤其难操作，通常只能依赖第三方 App 且广告多。

因此需要一个**网页端、免安装、跨设备**的视频下载工具：粘贴链接即可解析并保存。

## 2. 项目目标

| 维度 | 目标 |
|------|------|
| 能力 | 覆盖主流 + 长尾站点（借助 yt-dlp 的解析能力） |
| 体验 | 粘贴 → 选清晰度 → 保存，全程 3 步，无注册即可用 |
| 性能 | 解析结果秒级返回，下载有实时进度 |
| 跨端 | 桌面与手机同一套界面，自适应布局 |
| 商业 | 首页具备付费转化引导（会员权益区），为后续变现留位置 |
| 成本 | 先不引入数据库；服务端存储按 TTL 自动清理，控制磁盘占用 |

## 3. 用户画像与场景

- **内容研究者 / 学生**：需要把公开课、讲座存档，追求高清晰度与字幕。
- **运营与创作者**：需要参考素材，追求批量与速度。
- **普通用户**：手机上一键保存喜欢的短视频，追求"能用、不折腾"。

典型场景：

1. 用户在 B 站看到想收藏的视频 → 复制链接 → 粘贴到本站 → 选 1080P → 保存。
2. 用户想下载 YouTube 视频的高码率版本 → 直链下载被防盗链拒绝 → 切换"代理加速"。
3. 用户手机浏览器打开本站 → 全宽搜索框 → 下载完成后直接存入相册/文件。

## 4. 功能需求

### 4.1 第一阶段（MVP，本期交付）

| 编号 | 需求 | 说明 |
|------|------|------|
| F1 | 链接解析 | 输入视频页面 URL，返回标题、封面、时长、作者、平台、可用清晰度列表 |
| F2 | 清晰度选择 | 展示真实可用格式（含 ext、预估大小、是否支持直链） |
| F3 | 服务端转存下载 | 后端下载并合并音视频，前端轮询进度，完成后提供下载链接 |
| F4 | 直链下载 | 解析出平台直链后由浏览器直接下载，不占服务器带宽 |
| F5 | 代理下载 | 后端流式转发直链，注入 Referer/UA，支持 Range |
| F6 | 进度反馈 | 下载进度、已下载大小、总大小、剩余时间 |
| F7 | 过期清理 | 服务端文件保留 1 小时后自动删除 |
| F8 | 限流与安全 | 单 IP 解析/下载频率限制、并发上限、SSRF 防护、大小上限 2GB |
| F9 | 付费引导 | 首页会员权益展示区（本期不接入真实支付） |

### 4.2 第二阶段（规划中，本期不做）

- 字幕下载与字幕翻译
- AI 视频总结（摘要、章节拆分）
- 用户体系：登录、下载历史、额度管理
- 真实支付：会员订阅、订单、发票
- 批量任务队列与 playlist 支持
- 下载历史与分享短链

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 解析请求 P95 < 8s（受平台响应影响）；下载支持并发分片 |
| 可用性 | 单任务失败不影响其他任务；进程重启后任务丢失可接受（本期无数据库） |
| 安全 | 拒绝内网/环回地址访问；限制单 IP 并发与频率；文件大小上限 |
| 合规 | 明确版权声明；不保存用户账号 Cookie；不代用户登录平台 |
| 可维护 | 下载能力全部委托 yt-dlp，本项目不修改其源码，升级仅需更新依赖 |
| 可移植 | 前后端分离，前端为纯静态产物，后端单进程可跑；支持 Docker 部署 |

## 6. 约束与风险

1. **版权与合规风险**：工具本身中立，但使用者可能下载无授权内容。需在页脚、README 显著声明。
2. **平台风控风险**：公网大规模使用可能导致服务器 IP 被平台限流甚至封禁。缓解：限流、默认不并发批量、建议加邀请码。
3. **直链时效性**：平台直链通常数小时失效，不能长期缓存。
4. **格式限制**：HLS/DASH 分离音视频格式无法直链，必须走服务端合并（依赖 ffmpeg）。
5. **无数据库**：任务状态在内存中，重启即丢；多进程部署需改造为共享存储。

## 7. 验收标准（本期）

1. 粘贴一个真实 YouTube/Bilibili 链接，能正确展示封面、标题与至少 2 个清晰度选项。
2. 选择"服务端转存"，进度条实时推进，结束后"保存到本地"可获得可播放文件。
3. 选择一个支持直链的格式，"直链下载"能启动浏览器下载；"代理加速"能在直链 403 的情况下成功下载。
4. 手机浏览器（375px 宽度）下页面布局正常，操作可达。
5. `/docs` 可访问 OpenAPI 文档；`/api/health` 返回服务状态。
6. 超时 1 小时后，服务端文件被自动清理。

## 8. 术语表

| 术语 | 含义 |
|------|------|
| 直链 | 平台 CDN 上可直接下载的媒体文件地址（通常带签名与时效） |
| 服务端转存 | 后端先下载文件到服务器磁盘，再提供给用户下载 |
| progressive 格式 | 音视频封装在同一文件中的格式（可直接直链下载） |
| DASH/HLS | 音视频分离的流式协议，需下载后合并 |
| yt-dlp | 开源视频下载引擎，本项目以其为唯一下载能力来源 |
